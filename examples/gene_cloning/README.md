# Gene cloning example

This directory contains an example output file generated by the gene cloning
workflow in `primer-designer`.

The primers shown here were generated using the example input sequence
`data/gene_example.fasta` with default primer design parameters. The output
demonstrates selection of viable forward and reverse primers that satisfy
standard length, melting temperature, GC content, and secondary structure
constraints.

The file is provided as a reference for the expected structure and
content of gene cloning primer outputs.
